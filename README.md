# MyTarot Day

> Não sou místico — a ideia foi puramente técnica.

Projeto de Tarot desenvolvido como dois desafios distintos.

## Desafio 1 — Multilingual e Determinístico

Criar uma aplicação de Tarot completamente **multilingual** (suporte a múltiplos idiomas) e **determinística** — os mesmos inputs sempre produzem os mesmos outputs, sem aleatoriedade oculta.

## Desafio 2 — Migração 100% para Kof

Migrar toda a aplicação para **[Kof](https://github.com/publiosantos/publab)**, eliminando dependências externas e rodando nativamente no runtime Kof.
